# Token Budgeting

Make sure to calculate the no of input and output tokens for every request to prevent abuse of services

- Apply rate limits 
	- no of tokens per time window
	- max tokens for input
	- max tokens for ouput
	- max tokens for a user (based on the subscription)
- Record token usage for invoices, stats and for tracebility (what goes wrong)

# Visibility / Monitoring

* **Structured Logging** By generating logs that capture the sequence of events, you can see exactly what happened during a process, these logs are typically saved in *LangSmith* / *Langfuse*.

* **Metrics Collection** This focuses on gathering quantitative data to build dashboards, allowing you to monitor trends over time.

	- **Request Totals :** The total number of requests processed by the system.
	- **Total Errors :** The count of failed requests, used to calculate the **Error Rate**.
	- **Latency :** Measured in milliseconds, this tracks how long each request takes. This is often tracked as a sum and count to determine **Average Latency**.
	- **Token Usage :** Monitors both **Input Tokens** and **Output Tokens** to track consumption and costs.
	- **Cache Performance :** Specifically tracks **Cache Hits** and **Cache Misses** to calculate the **Cache Hit Rate**.

* **Traces** Traces track every input, output, and millisecond of activity, revealing how agents make decisions, which tools were called, and how components interact with one another.
